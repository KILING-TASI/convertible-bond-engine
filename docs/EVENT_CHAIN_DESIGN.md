# 当前有效条款证据链与首批验收

## 已有能力

v0.8已有募集说明书底稿、巨潮公告候选、人工正文核对声明、实际PDF指定字段匹配、历史行情降级和按逐日转股价观察计数。它们不等于全部当前条款已经核验。DV01、久期、凸性和逐期限插值已存在，不另起重复实现。

## 首批新增

v0.9生成event_chain：原始条款单列；公告按公开日期组织；实施日分列。晚于截止日的公告不纳入，已公开但尚未实施的调整不进入历史有效价候选。仅正文底稿确认的调价生成候选，并保留实际PDF匹配的字段范围。同日价格冲突和前后价格不衔接形成缺口，不自动选当前价。

强赎、不强赎、下修、回售及调价公告复用现有分类和正文底稿。没有全部事件覆盖证据时，current_state各项都保持unknown，不因目录没有命中而给安全结论，不以不赎回承诺消除信用/股价风险。事件链不自动回写analysis_input。

观察底稿新增calendar_complete和halted_days。完整性未声明时，观察计数仍可展示但正式结果未知。声明停牌日不得同时填收盘价；其缺记录只在显式停牌清单内允许，其他缺日拒绝。停牌计数约定未核验时暂停计数，不自动把停牌日从窗口排除，不前向填价。日历本身的真实性仍须外部核验。

## 真实样本与验收

首批仅113042上银转债。复用本地真实原始募集说明书、2026-06-02调价公告及2026-10-09巨潮目录快照；原始条款与8.57→8.35、2026-06-08实施的候选分开。已有PDF核验只覆盖列出的字面字段，不扩大为完整法律解释或全部公告核验。

验收要求：公开日晚于截止日的事件被排除；实施前不提供有效价候选；标题候选不改变权利状态；冲突价有缺口；停牌不填价也不默默删交易日；未确认覆盖不产生安全状态。教学故障测试与真实样本运行分别记录。

## 后续与缺口

尚缺全部后续调价/不赎回/不下修/回售的正文核验，权利承诺的起止与重置约定、公告更正关系及历史有效价完整性证明。尚无全市場数据库、正式可执行风险日历或历史回测信息集。不能从单券成功推导全市场覆盖。

## 固收扩展顺序

1. 现金流：确认兑付日、末期含息、净价/全价/应计息、计息起止和税务口径，区分实际与假设。
2. 日计数与期限：现为ACT/365F年复利；后续按证券合同支持其他基准和结算日期，不混用。
3. 曲线：记录报价类型、期限、历史时间与信用口径，先核对即期率/贴现因子；未来再引入可审计bootstrap与曲线版本，不能把到期收益率节点直接冒充零息率。
4. 风险：复用现有平行移动DV01/久期/凸性；之后添加节点冲击及关键利率久期，并核对与平行冲击的关系。
5. 含权、OAS与发行人博弈：排在上述证据和现金流/曲线口径之后，分别说明模型价、信用假设和样本外验证，不宣传已经完成。

外部缺口调研仅用于选题，不沿用“零竞争”等未经复核结论。
