# 教学情景实例验收

主分支之外的待审增量，未发新版。只把已有有意义测试/样本整合为短CLI入口，补一年现金流手算锚点和真实CLI/报告回执，不新增定价模型或真实数据采集。

```sh
python -m pip install .
python -m cbengine.scenarios --example-dir examples --out-dir local-data/scenarios-first-run
```

Python3.10+、核心标准库，无其他自家仓依赖。打开新目录index.html；每个场景保存input.json、必要analysis.json、receipt.json（预期/实际/错误/输入摘要/方法版本），正常场景另有原生结果。目录已存在拒绝，不覆盖旧文件。条件计数案例生成已有HTML资料卡，页面不重新定价。

## CN使用情景独立补充批

复用上批净全价、末息、支付日、非平坦和条件满足/未公告案例，避免重复凑数量。本批4组、5个CLI调用：

```sh
python -m cbengine.scenarios --cn-only --example-dir examples --out-dir local-data/cn-scenarios-first-run
```

[官方依据登记](CN_SCENARIO_SOURCES.json)保存核验日2026-10-10、历史/现行版本、条文/页码、支持条件及摘要；完整DOCX/PDF不进源码或包。上交所2025年3月修订交易细则官方页面标现行有效，已读取官方附件第5/6/13条；上银公告及募集说明书只作指定历史字段参考，未知首次可得/当前全量条款不填。

1. 沪市全价报价以每100元面额计，不等于交易申报面额或转股整数股。原生桥不支持交易/转股操作数量，额外quantity字段拒绝；不新增下单/转股算法。
2. 公告旧8.57、新8.35、6月8日实施；两日正股10.86为**合成价格**，6月5日窗口旧价延用亦为教学假设，不是真实首次生效历史。明确30/15原始条款参考，尚缺完整调价/承诺/重置/日历。独立乘法门槛11.141与10.855，历史计数1而不是用新价重算得2；正式状态仍unknown。
3. 原公告“暂停转股”不直接认定正股停牌。另造明确标教学的交易停牌输入：删去该日价格但保留日历后count=null，计数政策unknown；停牌日同时带可交易价格则拒绝，不自动填价/排除。
4. 原始募集说明书区分付息登记、支付窗口、税务承担；不推定真实到账日、统一税率或券商费用。桥接输入的fees/cash_arrival_date不受支持时拒绝，不默默并入税额或现金流日期。

[本批教学汇总](CN_SCENARIO_ACCEPTANCE.json)与新目录保存输入/分析/预期/实际/错误及方法cn-scenario-acceptance-1，正常历史赋价/未知停牌场景生成已有中文资料卡。金额人民币，报价每100面值，股价/转股价元每股；fetched_at为教学北京时间，不作真实可得时刻。输出目录已存在拒绝，旧12场景及冻结回执不覆盖。独立单仓wheel CI另跑此模式并保存详细回执。

本批没有真实市场/账户数据验收、实际日历/停牌计数认证、费用/到账模型、新视觉或含权模型。原规则库不被静默升级；此处只核指定制度/历史样本条件。资料与数据权利保持，不合并/发版/自动安装，以4组代表情景和边界拒绝的实际CLI结案。
