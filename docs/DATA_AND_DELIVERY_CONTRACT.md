# 数据、职责与交付契约

核对日：2026-10-10。本文件是本仓库详细职责/状态/版本说明的权威入口；实际数据入口在[单一目录](DATA_ENTRY_CATALOG.json)，专业算法仍以[方法卡](FIXED_INCOME_METHOD_CARDS.md)为准。本批只盘点、提案与既有样本复核，不扩全市场取数或后台更新。

## 职责与独立运行

核心负责显式转债现金流、年有效零息曲线、条件收益率、固定现金流风险、条款观察及原文/调价证据缺口。不认证完整含权价值、发行人实际决定或交易执行。可独立安装运行，不需要工作台：

```sh
python -m pip install .
python -m cbengine.bridge examples/bridge-fixed-demo.json --out-dir local-data/data-contract-demo-first-run
```

新目录输出输入和结果，已有目录拒绝。行情可选.[market]、PDF可选.[evidence]、QuantLib仅独立对照。公司经营与综合投资判断留工作台；财报库不因此成为估值审计平台，穿透库不做基金全评价，MarketLens不做全部公司事件库，规则库不扩事件平台。工作台只可选调用独立引擎，不承载新共用底座。

## 实际入口与专业口径

目录逐项记录命令/模块、原发布者/获取渠道/接口库、身份、单位币种频率、时间精度、版本/摘要/更正、覆盖与更新、权利及维护者。实际已跑、教学、调用者声明和未验证分开。没有本轮联网取数；旧文档里的真实验收只代表当时单样本。

七组是行情、公告目录、原始PDF、现金流、曲线、日历/调价、规则参考。报价未核净全价不能直接用于定价；第三方债底不变成本引擎估值。收益率为小数、金额每100面值、现金流和观察日保留各自频率，不强迫统一数据商或日频。

取得时间不是历史可得时间。quote_time日期/null、公告published_on日期、生效effective_on日期、fetched_at带时区时间及reviewed_on核对日期分别保存；首次历史可得时刻通常unknown，不能替换成取得或公告日期以制造无前视回测。下载成功、原页定位、字面字段匹配与完整语义核验也不互相替代。

## 契约差异与最小共用头提案

[source-envelope-proposal.json](source-envelope-proposal.json)只示范对既有113042调价底稿增加旁路头，保留professional_payload全部专业字段。schema_version=cb-source-envelope-proposal-0是**未实现的设计**，不是已支持接口；不新增解析器或共享服务，也不让旧bridge入口默默接受信封。传此信封到现有严格固定现金流接口会因不兼容字段被拒绝，未来需明确适配或迁移。

提案分开publisher/channel/library、观察/发布/生效/取得/可得时间与精度、原始版本/更正关系/原件摘要、输入摘要和解析/语义状态。底稿reviewed_on不填入retrieved_at，文档哈希是已有声明而不是本轮下载认证；历史available_at与supersedes仍null。派生IRR、债底及条款结论独立保存，不写回原始事实。

本仓库三条旧契约并存：市场快照schema_version=1；显式桥cb-fixed-cashflow-1；原文核验底稿及字段绑定。它们身份、来源及日期含义不同，不通过改顶层schema数字静默互换。字段有值不等于已确认，缺值/冲突/失败保持原有专业状态，不统一映射为0或safe。

## 重复入口与跨仓复用实际范围

- 比价表与历史降级都在market模块；同一报价路径仍保留所选来源/失败记录，不能拼较新正股价到较旧转债行。
- 公告候选查询与coverage分页审计存在渠道重合，但前者发现线索，后者保留页证据，不以分页完整替代法律事件完整。后续可复用同一原始响应，本批不合并不同契约。
- 原始条款、正文底稿、PDF匹配与档案可共享原件哈希，但层级不同；只在本地留PDF原件，不发布全文。
- 工作台内置现金流诊断与独立桥有平坦数学交集，入口保持各自独立。既有三组可转债跨仓原生调用已实际验收，本批只复核冻结输入摘要与状态：[复核记录](DATA_REUSE_CHECK.json)、[实际联合回执](native-bridge-final-32e42b4/summary.json)。没有重新执行或升级旧回执。

2026-10-10已按授权协调MarketLens任务。其反馈公告record-evidence/Store.add_evidence与叙事available_at/verified_at分别存在，但无下载器、PDF解析或原页认证；它不能把本引擎PDF字面匹配直接当法律语义确认。尚无真实共同公告样本或稳定跨仓接口，故该链**待验证**。本文件不替对方代码或所有材料认证。

四条优先链中，本仓库覆盖公告原文与行情/交易日历的专业盘点；基金净值+分红拆分、宏观修订序列由对应任务负责，本仓库未实现其数据链。不宣称九仓数据已统一。
